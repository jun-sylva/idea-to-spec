# Extension de profil — Lean

Utiliser pour un cadrage rapide et réversible. Conserver les huit documents canoniques, mais les rendre concis.

## Minimum attendu

- un problème et un résultat mesurable ;
- utilisateurs et parcours principal ;
- périmètre inclus et exclu ;
- hypothèses les plus risquées ;
- exigences du prochain lot avec critères d'acceptation ;
- risques majeurs et décisions ouvertes ;
- tâches suffisantes pour lancer le prochain lot ;
- validations intermédiaire et finale.

Les sections sans contenu pertinent peuvent indiquer « Non applicable — [raison] ». Ne jamais utiliser cette formule pour éviter une vérification de sécurité ou de conformité nécessaire.
